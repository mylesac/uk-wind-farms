# UK offshore wind

An interactive map of UK offshore wind farms, showing live and forecast wind speeds at each site and the current GB generation mix.

**Live site:** https://mylesac.github.io/uk-wind-farms/

- Wind forecasts: [Open-Meteo](https://open-meteo.com/)
- Grid generation: [Elexon BMRS](https://bmrs.elexon.co.uk/), with a fallback to the [NESO Carbon Intensity API](https://carbonintensity.org.uk/)
- Coastline: [Natural Earth](https://www.naturalearthdata.com/)

The whole site is the single file `index.html`. It needs no build step.
